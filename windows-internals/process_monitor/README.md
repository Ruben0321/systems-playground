# Process Monitor

Educational Python tool for learning basic Windows process monitoring.

## Goal

This project helps me understand:

- processes
- PIDs
- CPU usage
- RAM usage
- system monitoring
- logging

## Current features

- List running processes
- Show process PID
- Show process name

## Planned features

- Show CPU usage
- Show RAM usage
- Filter process by name
- Save process report to a text or CSV file
- Add auto-refresh mode
